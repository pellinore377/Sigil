Sigil native dependency notices (client, Android and server egress)

This supplements Server-ThirdParty.txt and Crypto-ThirdParty.txt for the native
Rust client and server egress. It does not cover Compose, fonts, icons or future platform adapters.
Cargo.lock pins exact versions. ureq enables rustls only; compression, cookies,
platform proxies and native-tls are disabled. tokio-rustls also serves native RTC.

The WebPKI root data is under CDLA-Permissive-2.0. The TLS implementation includes
MIT/Apache-2.0/ISC components, including ring's upstream and bundled-code notices.
The server's provider HTTPS adapter uses this same pinned HTTP/TLS stack.
The native client's WebPush encryption/decryption dependencies share the exact
versions and MIT notices in Server-ThirdParty.txt, including the documented local
ece-native 0.5.0 framing patch. Distribute these notice files together.
