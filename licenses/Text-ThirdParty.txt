jiff-core 0.1.0, and jiff-tzdb 0.1.8 (IANA 2026c). No operating-system timezone
lookup, JavaScript, network fetch or runtime host timezone data is enabled.
The bundled database version is checked before recurrence computation.
Portable atomic components are included for target compatibility. Dormant
optional/cfg-disabled macro dependencies remain Cargo lockfile entries; they
are not enabled in this package's build. The MIT options follow.
